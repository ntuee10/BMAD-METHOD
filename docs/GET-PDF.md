## 🚀 3 Ways to Get Your PDF (Choose One)

### Method 1: Browser Print (EASIEST - 30 seconds)

1. **Open the HTML file in your browser:**
   ```bash
   # macOS
   open docs/comprehensive-user-guide.html

   # Linux
   xdg-open docs/comprehensive-user-guide.html

   # Windows
   start docs/comprehensive-user-guide.html
   ```

2. **Click the green "Print to PDF" button** at the top-right

   OR press `Ctrl+P` (Windows/Linux) or `Cmd+P` (macOS)

3. **In the print dialog:**
   - Destination: **Save as PDF**
   - Layout: Portrait
   - Pages: All
   - Click **Save**

4. **Done!** Your PDF is ready.

**Estimated file size:** 1-2 MB

---

### Method 2: Command Line (Chrome/Chromium)

```bash
# If you have Chrome or Chromium installed:

google-chrome --headless --print-to-pdf=BMAD-Guide.pdf docs/comprehensive-user-guide.html

# OR with chromium:
chromium --headless --print-to-pdf=BMAD-Guide.pdf docs/comprehensive-user-guide.html
```

## 🔧 Troubleshooting

**Issue: PDF is too large**
→ Use browser print settings to reduce quality or choose "Optimize for file size"

**Issue: Code blocks are cut off**
→ In print dialog, set margins to "Minimum" or "Custom" with 0.5 inch margins

**Issue: Colors don't print**
→ In print dialog, enable "Background graphics"

**Issue: Can't open HTML file**
→ Drag and drop `comprehensive-user-guide.html` onto your browser window
